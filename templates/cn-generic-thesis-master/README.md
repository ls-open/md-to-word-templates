# 通用中文学位论文（硕士）

取多数高校研究生院要求的交集：A4、上下 2.54cm、正文小四 1.5 倍行距、章标题三号黑体居中、
三线表、公式按章编号、双线章名页眉、前置件小写罗马页码。

## 拿这份模板怎么用

```bash
md-to-word 你的稿件.md -f format.txt -o 你的稿件.docx
```

先照 `sample.md` 的结构写稿，再往里填内容；`sample.md` 与 `format.txt` 一起读，条目一一对应。

## 和多数学校的差异点

学校文件通常在这几处各自加码，抄过去后改这三行就够：

- 行距：有的要求 20 磅固定值（改成 `行距20磅`，我校验过会触发「公式被裁」的预检提醒）
- 标题字体：有的要求方正小标宋简体而非黑体
- 章节编号：有的要求 `第1章` 而非 `第一章`，改标题文字即可，格式文件不用动

## 已知限制

- 未覆盖封面的具体版式（各校差异极大，请用 `{{< section 页眉=无 页脚=无 >}}` 单独排一节）
- 未声明 `四级标题`～`六级标题`：多数学校不用；要用请补声明行
- 公式按章编号已开启；附录编号需要 `附录公式编号格式` 行，本模板未写
